# Validation evidence / 验收记录

Initial development date: 2026-10-12.

Apple redirect review (2026-10-13): compared current Xzese transport and pyicloud trust_session source. Xzese's generic three-redirect cap was reused unchanged; pyicloud requests browser trust before token authentication. Authentication GET requests now allow up to eight same-origin redirects within the unchanged timeout, while other requests retain three. Intermediate allowlisted session headers are preserved, refreshed authentication context is used on follow-up hops, and missing Location, excessive hops and identical-request loops report APPLE_REDIRECT_ERROR with stage/status/count only. New tests complete trusted-device login with four trust redirects and verify intermediate cookies/tokens; missing destinations cannot persist a login, and loop diagnostics expose no query/header secrets. The operator's actual redirect response and Apple login completion remain unverified.

First-run D1 fix (2026-10-13): local workerd with a fresh, uninitialized D1 reproduced the operator's UPSTREAM_UNAVAILABLE status failure before any Apple request. Tests previously initialized schema outside the Worker, hiding this case. Worker now initializes only missing tables from build-embedded schema.sql, checks required columns and preserves existing records. New SQLite tests cover concurrent initialization, restart preservation, failed-initialization retry and refusal of incompatible schemas/destructive SQL. The workerd test now starts with empty D1 and verifies management status succeeds without Apple traffic. This is a reproduced local cause; the operator's actual production database has not been inspected.

2026-10-13 runtime binding fix: a new regression test first reproduced CONFIGURATION_REQUIRED with a valid 44-character Base64 Secret exposed through a non-enumerable getter. The Access adapter's `{...env}` dropped that binding and D1. The fixed per-request context forwards binding reads to the original env receiver without enumeration or shared mutation. The regression now passes; missing Secret and invalid key format have separate messages. This identifies a reproducible source defect, not proof of the operator's exact production binding descriptors. Latest checks include the separately merged Find My implementation; production resolution still requires deployment and retry.
