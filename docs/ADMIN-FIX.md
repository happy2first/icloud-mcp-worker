# 首页及网页服务授权修复（2026-10-13）

首页改用“授权访问”“继续授权”“检查连接”，隐藏 PCS 术语和重复提示。七张服务卡片包含查找；查找继承网页登录，无需 PCS 授权或新增环境变量。查找检查仅列出设备，不刷新定位或播放声音。

照片、备忘录等未完成授权时禁用检查按钮，设备批准与数据准备有不同提示。后端仍强制检查授权状态。错误保留安全的协议详情和 DAV 诊断。

pyicloud 的 requestWebAccessState 允许省略 isICDRSDisabled 和 isDeviceConsentedForPCS；此前代码要求前者必须为布尔值。现在省略字段时继续请求具体 appName 的 requestPCS，只有服务响应明确成功才标记可用。显式拒绝、错误字段类型、未知协议及等待响应都不能被当成授权成功。设备批准等待和 Cookie 上传等待仍有倒计时及次数/期限限制。

网页服务的会话恢复开关改为与已授权默认值一致，未配即开启。请求边界和非安全操作的重试限制保留。

166 项测试、类型检查、构建和本地 workerd 通过，包括省略字段、授权等待、未知协议脱敏、未授权按钮禁用以及管理页查找检查。合并最新 DAV 修复，保留其诊断。用户已确认 Apple 网页登录成功；本次照片/备忘录生产授权仍待部署后确认。

## 补充截图：提醒事项 requestPCS HTTP 412

- 用户补充错误显示 requestPCS (reminders) 返回 HTTP 412，两个验证字段均未返回。此前代码将所有 412 都解释为设备验证失败，诊断过于确定。
- 对照 timlaing/pyicloud 当前 base.py：isICDRSDisabled 未返回时默认 false，跳过 PCS 请求；本项目此前反而请求 PCS。现修正可选字段默认行为。明确的设备验证/浏览器信任拒绝仍然阻止访问，非法字段与错误响应不会当作成功。
- 数据访问准备接口返回 412 且没有明确验证信号时，返回带阶段、区域、HTTP 状态的 PROTOCOL_CHANGED，而非直接要求重新登录。不自动重放，不删除凭证。真实登录验证接口的 412 判断保持不变。
- READY 只表示完成数据准备；管理页仍以真实服务读取通过为连接正常条件。新增缺字段、不绕过验证、412 分类测试，并用本地 workerd 验证缺字段时跳过 PCS 后真实读取云盘。
- 189 项测试、类型检查、构建、本地 workerd 通过。生产 requestWebAccessState 响应未获取，当前差异能否解释全部 412 尚需部署后复测，不宣称已通过真实 Apple 验收。

## 查找单独拒绝网页登录会话

- 用户确认其他六项服务连接成功，查找返回 REAUTH_REQUIRED。原诊断未附实际 HTTP 状态；不能据此认定整个网页登录失效，更不能要求更换 App 专用密码。
- 对照 pyicloud 的 Find My 强制重新认证分支，本项目此前的强制恢复仍优先 /validate；通用验证成功时未交换 Token，可能沿用被查找拒绝的 Cookie。现为只读查找补充一次保存 Token 的 accountLogin 交换并重建客户端，不保存密码；仍保留账户、验证、条款和区域校验。
- 无 Token 时保留记录并明确提示；再次被拒绝时保留冷却，不无限重试。播放声音路径仍禁止自动恢复后重放，不发送实机声音进行验证。
- 诊断附服务接口、区域、目标主机和 HTTP/响应 statusCode，不输出 Cookie 或 Token。卡片错误按凭证类型提示；播放声音说明明确为 MCP 支持的主动操作，需用户确认目标设备。服务器已保存的同一错误不重复展示第二个全文框。
- 回归覆盖中国大陆区 Cookie 交换、二次拒绝及冷却、Token 缺失、主动操作不重放、详情去重后仍可复制。真实 Apple 查找尚需部署后复测。

## 保存 Token 交换被 Apple 拒绝

- 用户复测返回 Apple rejected the saved authentication tokens。这是保存 Token 的交换拒绝，并不能凭该诊断推断具体 HTTP 状态，也不能靠重复重试获得新 Token。核对参数与 pyicloud 的 token 交换一致，尚无证据可确认新的请求参数修复。
- 修正上一轮的错误处理：因查找触发的 Token 交换失败不再清空共享网页登录记录，也不接受失败响应删除的 Cookie 或返回的新 Token。查找失败与冷却信息独立保存，其他服务不受这个本地失败状态阻断。
- 账号登录/验证的认证拒绝补充阶段、区域、HTTP 状态及安全布尔字段。通用错误不再建议一律更换 App 专用密码。
- 回归覆盖大陆区查找 421 后 accountLogin 401 并删除 Cookie 的响应：原始凭证完整保留，再次查找不重试，备忘录操作仍可使用原共享会话。真实 Token 若不可再用，恢复查找仍可能需要用户重新网页登录和验证一次。此前版本已经清除的记录不能由本次补丁恢复。
